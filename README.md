# Cakes JL Confeitaria

Catálogo de tortas e bolos, brownies e donuts sob encomenda, com montagem do pedido para envio pelo WhatsApp. Cakes JL Confeitaria, em Gravatal/SC.

[Acessar o site](https://www.cakesjlconfeitaria.com.br/).

## Estrutura

- `index.html`: página inicial.
- `tortas/`, `brownies/` e `donuts/`: catálogo e fotos dos produtos.
- `pedido/`: carrinho e finalização do pedido.
- `assets/`: estilos, scripts e ícone do site.
- `logo.png` e `CNAME`: marca e configuração do domínio.

## Manutenção

Site estático em HTML, CSS e JavaScript, sem instalação ou etapa de build. Ao atualizar produtos, manter os preços dos HTMLs e de `assets/pedido.js` alinhados.

Publicação pelo GitHub Pages, mantendo a estrutura das pastas. Preservar o `CNAME` no repositório oficial e deixá-lo de fora dos repositórios de teste.
